# 校园社团助手 · 官网

HarmonyOS 应用「校园社团助手」的官方网站（纯静态页面，无后端、无依赖）。

| 页面 | 说明 |
|---|---|
| `index.html` | 官网首页：应用介绍、功能特点、界面示意、应用信息 |
| `privacy.html` | 隐私政策 |
| `icon.png` / `favicon.png` | 应用图标（与安装包内图标一致） |

## 本地预览

用浏览器直接打开 `index.html` 即可，不需要任何环境。

## 部署到 GitHub Pages

1. 仓库 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存
3. 稍等 1 分钟后访问 `https://<用户名>.github.io/<仓库名>/`

隐私政策地址即 `https://<用户名>.github.io/<仓库名>/privacy.html`。
